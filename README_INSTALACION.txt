PERLENTAUCHER - PILOTO INDIVIDUAL V1
====================================

OBJETIVO
Esta edición está pensada para pruebas individuales: cada compañero mantiene sus propias obras, categorías e incidencias en su dispositivo/navegador. No comparte ni sincroniza datos con otros usuarios.

IMPORTANTE
- No borrar los datos/caché del navegador durante el piloto.
- Usar siempre el mismo navegador y la misma URL en cada dispositivo.
- Los datos de esta edición son locales al navegador.
- La aplicación permite seleccionar o arrastrar/soltar fotografías, documentos y planos PDF.
- En esta edición piloto los adjuntos sirven para probar el flujo y sus referencias; la persistencia completa de archivos y el visor/anotador PDF se completarán en la fase posterior de almacenamiento/sincronización.

ESCRITORIO - PRUEBA RÁPIDA (WINDOWS / MAC)
1. Descomprimir el ZIP.
2. Abrir index.html con Chrome o Edge.
3. Introducir el nombre del usuario en Configuración.
4. Crear una obra y empezar a registrar incidencias.

ESCRITORIO - INSTALACIÓN COMO APP
Para instalarla como aplicación independiente, la carpeta debe publicarse en una URL HTTPS.
1. Abrir la URL con Chrome o Edge.
2. Menú del navegador > Instalar PERLENTAUCHER / Instalar aplicación.
3. Abrirla después desde el icono instalado.

IPHONE / IPAD
Requiere que la carpeta esté publicada en una URL HTTPS.
1. Abrir la URL en Safari.
2. Compartir > Añadir a pantalla de inicio.
3. Abrir desde el icono PERLENTAUCHER.

ANDROID
Requiere que la carpeta esté publicada en una URL HTTPS.
1. Abrir la URL en Chrome.
2. Menú > Instalar aplicación / Añadir a pantalla de inicio.
3. Abrir desde el icono PERLENTAUCHER.

RECOMENDACIÓN PARA EL PILOTO
Publicar una sola copia de esta carpeta en una URL HTTPS. Todos pueden abrir la misma URL, pero cada navegador conservará sus datos de forma independiente. Así todos prueban exactamente la misma versión sin compartir obras.

ARCHIVO MAESTRO
Conservar PROYECTO_MAESTRO.md y este paquete completo. Las futuras modificaciones deben partir de esta versión para mantener las decisiones funcionales acordadas.
